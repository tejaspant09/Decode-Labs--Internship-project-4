# General Knowledge Quiz
## About the Project
This is a simple General Knowledge Quiz made using Python. The program asks the user three questions one by one. If the answer is correct, the score increases by one. At the end of the quiz, the total score is displayed along with a message based on the user's performance.
This project was created to practice basic Python concepts such as variables, user input, conditional statements, and simple program flow.
## Features
* Asks three general knowledge questions
* Checks whether the user's answer is correct
* Calculates the total score
* Displays the final result
* Easy to understand and beginner-friendly
## Technologies Used
* Python 3
* Visual Studio Code

## How to Run
1. Make sure Python 3 is installed on your computer.
2. Download or clone this project.
3. Open the project folder in Visual Studio Code or any Python IDE.
4. Open the terminal in the project folder.
5. Run the following command:
```bash
python quiz.py
```
6. Answer the questions in the terminal and view your final score.
